# 수학도서관 예비고1 얼리어답터 관리

예비고1 학생이 희망 고교 3곳의 기출 시험지(학교당 2장)를 풀어 본 결과를 기록하고, 응시한 학교 중 **지원에 가장 유리한 학교**를 판단하는 앱입니다.

- 주소: https://hongs-sudo.github.io/early-adopter/
- PC·아이패드·핸드폰에서 같은 자료를 실시간으로 함께 씁니다 (Firebase Firestore).
- 앱으로 설치할 수 있습니다 (PWA). 핸드폰에서는 점수 입력·판단 결과 위주의 화면이 나옵니다.
- 원장 계정과 원장이 등록한 선생님 계정만 로그인할 수 있습니다.

## 판단 방법
1. 학교별로 학생의 시험지 점수 평균을 냅니다.
2. 학교알리미 고1 수학 1학기 평균·표준편차(2023·2024 평균)를 기준으로 학교 안 예상 위치(상위 %)를 계산합니다.
3. 가장 위치가 좋은 학교를 '유리', 5%p 안쪽은 '비슷', 그 밖은 '불리'로 봅니다. 5%p 안쪽이면 공부 성향 → 1등급 자리 수 → 지망 순서로 정합니다.
4. 성별로 갈 수 없는 남고·여고는 판단에서 뺍니다.

## 파일
- `index.html`, `style.css`, `app.js` — 앱 화면
- `firebase-config.js` — Firebase 웹 앱 설정 (공개 식별 정보)
- `sw.js`, `manifest.webmanifest`, `icons/` — 앱 설치·오프라인

학생 자료는 이 저장소에 들어 있지 않습니다. 모두 로그인으로 보호된 Firestore에 있습니다.

## 학부모 리포트
- 2차(4~6회)까지 끝나 최종 판단이 나온 학생만 보낼 수 있습니다.
- PC·아이패드: 학생 상세 → 학부모 리포트 (이미지로 복사 · 인쇄/PDF · 링크). 핸드폰: 학생 → 학부모 리포트 보내기.
- 링크(`r/?k=…`)는 로그인 없이 열리고, 보낸 날부터 30일 동안만 열립니다. 학부모 쪽은 열람·확인·상담 요청 기록만 남길 수 있습니다.
